# Twirl

> Twirl (twirldata.com) is a data platform / orchestrator that lets teams build data products faster by combining BigQuery, dbt, Python, and Google Cloud services (GCS, Dataflow) in a single git-backed project. Backed by Creandum. As of July 2026 the company's website (twirldata.com) and documentation site (docs.twirldata.com) return 404 and no public API surface is available; the only remaining public artifacts are the GitHub examples repository and a placeholder PyPI package.
